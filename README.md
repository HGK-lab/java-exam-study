# 자바심화 시험 대비

모바일 웹으로 보는 자바심화 시험 대비 자료입니다. 장별로 요약, 암기카드, 퀴즈, 오답노트를 제공합니다.
교수님이 강조하신 내용은 **(교수님 강조)** 표시가 붙고, 각 탭에서 "교수님 강조만" 필터로 모아 볼 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 홈. 장 선택 |
| `chapter.html` + `app.js` | 장 화면 (요약 / 암기카드 / 퀴즈 / 오답노트) |
| `data/chapters.js` | 장 목록. `ready: true`인 장만 열림 |
| `data/chXX.js` | 장별 내용 (sections, cards, quiz) |

오답 기록은 브라우저 localStorage에만 저장됩니다.

## 새 장 추가

1. `data/ch08.js`를 `ch07.js`와 같은 형식으로 만든다.
2. `data/chapters.js`에서 해당 장을 `ready: true`로 바꾼다.

내용은 강의 슬라이드를 직접 요약한 것이며, 원본 슬라이드는 포함하지 않습니다.
